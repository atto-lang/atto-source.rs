> **Canonical Atto PR governance:** [atto-lang/.github/AGENTS.md](https://github.com/atto-lang/.github/blob/main/AGENTS.md) is authoritative. A local summary does not override effective GitHub branch protection, CODEOWNERS, security restrictions or required material CI.
>
> **One independent owner approval per PR:** Exactly one actual GitHub `APPROVED` review from **either** `the1mills` (GitHub ID `2148448`) **OR** `ORESoftware` (GitHub ID `11139560`) is the review target. Never require both. No self-approval: the reviewer must not be the PR author. An old dismissed/revoked review, requested-only review, or unresolved `CHANGES_REQUESTED` never counts. Once GitHub retains a valid approval, ordinary pushes, rebases and merges from `main` do **not** demand another human approval. Effective stronger GitHub rules still apply until independently migrated.
>
> **No Ready-age review windows:** Review eligibility does not change at 72h, 240h or 10 days. No mandatory AI provider reviews, periodic review renewal, second human vote or separate age-gated quorum. Perform and document the mandatory competing/overlapping-PR audit before **every** merge, not only in one time window; retain exact-current-head source CI, security and merge-conflict checks.
>
> **Drafts and holds:** At >=72 consecutive hours in the CURRENT Draft cycle, automatic promotion requires genuinely passing exact-head material CI, verified current labels, no hard restriction and triaged competing work. The latest genuine Draft→Ready event starts a new Ready state; it does not add review slots. The Draft clock restarts only on a legitimate Ready→Draft conversion, never on a push. `keep-as-draft`, `keep-draft` and `not-ready` prohibit automatic promotion **and** automated merging. Check labels, HEAD, CI and protections immediately before action; never manipulate state to game clocks.
>
> **Security:** Approval policy text is not merge authorization or private-source copying permission. Respect GitHub protections, CODEOWNERS and source-security gates. Only use an authorized private SHA-verified Git-tree carrier after confirmed CI capacity/billing blockage and destination-specific confidentiality authorization; never use cross-org checkout tokens. Consult the [legacy Oreslang migration map](https://github.com/ores-truffle-oreslang/.github/blob/main/governance/atto-migration-map.json) before duplicating feature work.
