# Legacy native compiler tests
The exact old `atto_immutable_parity.rs` is preserved here (original Git blob 36669afd6aa168d61cb536ab1ab23afc1e5c0ab6). It targeted the separate native Rust/Cranelift crate `oreslang_source_rs` and its frontend/MIR/object API, not the active `atto_compiler` browser library. Its native artifact, explicit export and native-only rejection assertions are not executed by the browser Cargo package; restore them in an independently buildable native crate before claiming native parity. The active browser test ports applicable scalar binding checks to real source compilation, asserts the actual diagnostic codes, admits explicit mutable `let` (a supported browser feature), and adds a source guest fixture to the existing native/wasm32 compiler conformance corpus. This is a profile separation, not a native parity pass.
