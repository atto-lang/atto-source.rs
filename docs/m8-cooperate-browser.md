# M8 first executable Rust/Wasm compiler safe point

The canonical Rust browser compiler `atto_compiler::compile(source)` now admits **only one bounded owned-i64 actor safe-point shape**: the actor `on_message(int amount): int` loop that uses explicit `rt cooperate;`, two separate local integer slots and monotonically increments its index by one. `src/actor_cooperate.rs` builds the typed `Plan` and five-operation IR from the **normal Rust lexer**, then emits a deterministic *no-import WebAssembly guest binary*. This is real compiled Wasm code, not a JS step interpreter or source string registry.

**Distinct guest ABI:** `m8_new(amount:i64)->handle:i64`, `m8_resume(handle:i64,budget:i32)->i32` where 1=YIELD and 0=DONE, `m8_result(handle)->i64`, `m8_pc(handle)->i32`, `m8_index(handle)->i64`, `m8_close(handle)`. The native Rust host compiler and wasm32-compiled browser compiler must emit **byte-identical** Wasm bytes. Source actor names live in a distinct `atto.m8.cooperate` custom section; no native imports or JS callbacks are permitted.

A **single Wasm instance is one isolated active frame**. Its nonzero generation handle invalidates after `close` and cannot regain authority upon reuse. The frame holds two owned i64 locals and a durable PC: 0 initial, 1 loop continuation after safepoint, 4 DONE. A resume slice consumes at most 1..65536 `rt cooperate` reductions, stores the state before YIELD and never re-executes a completed addition. Both overflow preconditions are checked before mutating persistent locals; arithmetic overflow traps and the frame becomes non-resumable. DONE is idempotent; result before DONE and close/resume after CLOSE trap.

**Fail closed:** borrow, critical-state access, `await`, `select`, extra statements, parameter/slot aliasing, alternate control flow and non-unit increments never generate M8 Wasm. Non-M8 existing source routes through the unchanged canonical browser compiler.

**Executed evidence required:** `cargo test --locked` for Rust plan/parsing, build actual native `attoc` and wasm32 compiler, run `tests/m8-cooperate.mjs` against the WASM compiler. Execute its produced guest in Node's WebAssembly VM for 100,000 loop iterations with 4-reduction slices, 65,536-reduction boundary, exact sum 4,999,950,000, stale generation, double-close traps, independent instance state, overflow trap and unsupported-effect failures.

**Limitations:** this separate M8 guest ABI does not yet implement the regular `atto.browser.guest.v2` actor host, language actor messaging, multiple simultaneous frames per worker, general ownership analysis, all expression types, NIO integration or `await/select`. No LLVM/Forge/.NET parity or hard-real-time guarantee is claimed. See [M8 shared contract](https://github.com/atto-lang/atto-common-source/pull/19) and [Java M7](https://github.com/atto-lang/atto-source.java/pull/16).
